# COSC-472: Network Security

This repository contains coursework, programming projects, and security research completed for **COSC-472: Network Security** at **Salisbury University**.

## Overview

This course focused on the principles and practice of network security, including security risks and countermeasures, cryptography, and the application of cryptographic techniques in networked systems.

Coursework combined hands-on programming with research and analysis of real-world cybersecurity incidents and security technologies.

## Coursework

This repository includes:

- **Cryptography Algorithms Implementation** – Implementation and analysis of cryptographic algorithms
- **Cryptography Algorithms Project Report** – Documentation and analysis of the cryptography project
- **Cloud Computing Security** – Research and presentation covering security considerations in cloud computing
- **Colonial Pipeline Ransomware Attack** – Analysis of a real-world ransomware attack and its cybersecurity implications
